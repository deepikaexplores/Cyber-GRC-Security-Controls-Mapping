# Security Controls Mapping & Gap Assessment | CloudNest Technologies Pvt. Ltd.

## Project Overview

This project presents a practical **Security Controls Mapping and Gap Assessment** for a fictional SaaS organization, **CloudNest Technologies Pvt. Ltd.**

The assessment maps key security requirements and identified risks to relevant **ISO 27001:2022 Annex A controls** and **NIST Cybersecurity Framework (CSF) 2.0 categories**.

The objective is to demonstrate how cybersecurity frameworks can be applied to identify control gaps and recommend practical improvements in an organizational environment.

## Company & Scenario

**Company:** CloudNest Technologies Pvt. Ltd.  
**Industry:** SaaS / Cloud Technology  
**Assessment Type:** Security Controls Mapping & Gap Assessment  
**Project Type:** Cyber GRC Portfolio Case Study

CloudNest provides cloud-based software services to business customers. Its environment includes customer data, employee accounts, cloud infrastructure, applications, endpoints, and third-party service providers.

## Objective

The objectives of this assessment are to:

- Identify key security requirements and associated risks
- Map relevant security controls to ISO 27001:2022 Annex A
- Map security outcomes to relevant NIST CSF 2.0 categories
- Assess the assumed current implementation status
- Identify control gaps
- Recommend practical remediation actions
- Demonstrate a structured Cyber GRC control assessment approach

## Scope

The assessment covers the following security areas:

## Frameworks Used

### ISO 27001:2022

Relevant **ISO 27001:2022 Annex A** controls were used to identify appropriate information security safeguards for the risks and requirements assessed.

### NIST CSF 2.0

Relevant **NIST CSF 2.0 Functions and Categories** were used to classify the cybersecurity outcomes associated with each control.

The mapping is not intended to represent a mandatory one-to-one crosswalk between the two frameworks.

## Assessment Methodology

The assessment followed this approach:

**Security Requirement → Risk / Gap → Control → ISO 27001 Reference → NIST CSF Category → Current Status → Recommendation**

Each control was assessed using a fictional current-state scenario.

Implementation status was categorized as:

- **Implemented**
- **Partially Implemented**

The assessment then identified gaps and proposed practical recommendations for improvement.

## Key Findings

The assessment identified several areas requiring improvement:

- MFA coverage should be extended beyond privileged accounts.
- Access reviews should be performed periodically with documented evidence.
- Security logs should be centralized and monitored across critical systems.
- Patch and vulnerability remediation should have defined ownership and timelines.
- Backup restore testing should be performed periodically and documented.
- Incident response procedures should be tested through tabletop exercises.
- Cloud configuration reviews should be performed regularly to identify misconfigurations.
- Supplier security assessments should be formalized using risk-based reviews.
